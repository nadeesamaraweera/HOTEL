# 🏨 Luxe Horizon Hotel Website

This repository features the **Luxe Horizon Hotel** website, built using HTML, CSS, JavaScript, and Bootstrap. The website offers a responsive and visually appealing design, providing comprehensive information about the resort, including interactive elements and smooth navigation across devices.

## ✨ Features
- 🖥️ **Responsive Design:** The layout automatically adjusts to various screen sizes, ensuring a seamless experience on desktops, tablets, and mobile devices.
- 🎨 **Interactive Elements:** Includes hover effects, modals, and smooth scrolling to enhance user engagement.
- 🧭 **Smooth Navigation:** A user-friendly navigation bar with intuitive links to different sections.
- 🏗️ **Bootstrap Framework:** Utilizes Bootstrap components for layout and responsiveness, ensuring a modern look and feel.

## 🛠️ Technologies Used
- 📜 **HTML5**: Used for structuring the content of the website.
- 🎨 **CSS3**: Applied to style the website with modern design features and layout techniques.
- ⚡ **JavaScript**: Enables interactive features such as form validation, modals, and dynamic content updates.
- 📦 **Bootstrap**: A responsive front-end framework used for building the website layout and components quickly.

## 📥 Installation
To view and test the website locally:

1. Clone this repository:
   ```bash
   git clone https://github.com/nadeesamaraweera/HOTEL.git
   ```
2. Open `index.html` in your browser:
   ```bash
   open index.html
   ```

## 🏡 Usage
- 🏨 **Hotel Overview:** Provides a general introduction to Luxe Horizon Hotel and its offerings.
- 🌊 **Resort Amenities:** Describes the various amenities and services available at the resort.
- 🛏️ **Room Booking Information:** Guides users on how to book a room at the hotel.
- 📞 **Contact Details:** Offers information on how to contact the hotel for inquiries.
